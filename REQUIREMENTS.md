# Requirements: user registration

- Users register with an email address.
- **Email addresses are case-insensitive.** `Alice@example.com` and `alice@example.com` identify the same user.
- Registering an email that already exists (under that rule) must be rejected.
- Surrounding whitespace is not significant. `" alice@example.com "` and `alice@example.com` identify the same user.
